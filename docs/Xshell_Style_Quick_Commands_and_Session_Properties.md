# 快速命令、工具栏和会话属性

参考用户提供的本机 Xshell 8 截图和 [Xshell 8 官方手册](https://www.netsarang.com/docs/Xshell8_manual.pdf) 中的 Quick Command Sets、Session Properties。当前实现的入口和使用方式如下。

## 快速命令

“查看 → 快速命令”下提供快速命令栏、快速命令管理器和快速命令窗格。栏和窗格共用同一个命令库，可分别显示或隐藏；管理器在没有活动终端时也可以打开和编辑，发送按钮此时不可用。

- 管理器支持命令集的新建、重命名和删除，命令的新增、编辑、说明、删除、上移/下移，以及 JSON 文件导入和导出。导入合并到现有命令库，重新分配标识，不覆盖已有命令。
- 命令按钮可拖动排序。当前命令集的前 12 项对应 Ctrl+F1～F12；会话属性中可以禁用这些快捷键。
- 命令可以选择发送后回车，也可以仅插入文本；多行内容会转换为终端换行。命令只发送到点击时的活动终端，不自动广播到其他分屏。
- 关闭、断线或正在重连的终端不能接收命令。脚本运行期间继续使用现有的输入互斥规则。
- 本机旧 `hornet.terminal.commands.v1` 命令读入默认命令集；首次保存新库后写入 `hornet.terminal.commands.v2`。新库包含命令集与命令，单文件不超过 1 MiB。
- 会话的“高级 → 快速命令集”可指定打开该会话时使用的命令集。命令库按本机保存；导入会话时如缺少对应命令集，会回退到可用的默认集。

### 快速命令按钮的颜色

在管理器中选择一条命令，或在快速命令栏/窗格的命令按钮上右键，即可编辑该命令的“按钮外观”。设置完成后点击“保存命令”。

- 跟随主题：使用当前应用主题的默认按钮样式，也适用于没有外观配置的旧命令。
- 纯色：选择单一背景颜色。
- 线性渐变：选择起始颜色、结束颜色和 0～360 度的渐变角度。
- 径向渐变：选择由中心向边缘过渡的两种颜色。
- 提供红、绿、蓝、橙及多组渐变预设。文字颜色可自动选择，也可手动指定；预览按钮只显示外观，不发送命令。
- “恢复主题默认”清除当前命令的自定义外观。颜色按命令独立保存，命令栏与窗格同步显示；重新加载和命令导入/导出都会保留。

外观只保存受校验的十六进制颜色、渐变类型、角度和可选文字颜色，不接受任意 CSS、图片或 URL。

## 会话管理与底部属性

通过“查看 → 会话管理器”或主机列表按钮显示左侧会话树。当前终端属性位于整个窗口的底部状态栏，显示名称、主机、用户名、协议、端口、说明和连接状态，随活动终端和分屏选择更新；主机列表或文件栏隐藏时仍然可见，不显示保存的密码。底部省略号按钮或 Alt+P 打开当前会话属性。

新建或编辑连接时，可在“连接 → 说明”输入多行备注，留空也能保存。说明随会话配置持久保存；底部空间不足时精简显示，悬停可以查看完整说明。未填写时显示破折号。

## 顶部工具栏

在顶部菜单、标准按钮、地址栏或链接栏区域右键，可以勾选菜单栏(M)、标准按钮(S)、地址栏(A)、链接栏(L)以及锁定工具栏(B)。这些开关和排列顺序保存在本机。

菜单栏隐藏后，标题栏保留菜单恢复按钮；Alt 加菜单助记键也能恢复菜单。Alt+D 会显示地址栏并聚焦快速连接。解锁工具栏后显示拖动手柄，可以拖动标准按钮、地址栏、链接栏的行顺序；锁定后手柄隐藏并禁止重排。链接栏可添加当前已保存的远程会话、移除链接或点击连接。

## 新建和编辑会话属性

属性窗口改为左侧分类和右侧设置，支持以下已接通的设置。

| 分类 | 设置 | 生效时机 |
| --- | --- | --- |
| 连接 / 用户身份验证 | 协议、名称、主机、端口、用户名、密码、认证方式、说明、分组 | 保存；端点和认证身份正在使用时禁止改变 |
| SSH | 已保存 SSH 跳板链 | 下次连接 |
| 保持活动状态 | SSH 保活间隔和连续未响应次数 | 下次 SSH 连接 |
| 重新连接 | SSH 异常断线自动重连、间隔和总时限；默认关闭 | 保存后监控该终端 |
| 终端 | 字符编码、协商终端类型、初始列数/行数、滚屏行数 | 编码、类型和初始尺寸在下次连接；滚屏即时生效 |
| 键盘 | 退格键 DEL/BS、回车键 CR/CRLF、视觉响铃 | 当前会话即时生效 |
| 外观 | 每个会话的字体、字号、配色、光标和闪烁；恢复继承全局设置 | 当前与之后打开的同一会话；不重建现有终端 |
| 高级 | 默认快速命令集、禁用快速命令快捷键 | 即时生效 |
| 文件传输 | SFTP/FTP 初始远端目录、FTP/FTPS 加密方式 | 下次连接 / 新建文件视图 |

用户名和密码保持相邻，密码默认隐藏，右侧眼睛切换明文显示；密码继续由系统凭据库加密保存，不进入会话配置或导出文件。

每个会话只保存其终端显示设置的覆盖项，其他项继承全局设置。活动连接可以修改外观和说明，现有传输保持原连接快照；改变主机、用户名、协议、端口、认证方式或跳板链时仍需关闭使用该配置的连接。

自动重连仅处理 SSH 传输连接关闭或失败，远端正常结束 Shell 时不触发；手动断开会暂停该标签的自动重连，手动重连成功后恢复监控。重连不会重发历史输入或快速命令。初始行列数用于打开 PTY，之后仍自动匹配窗格尺寸。

会话设置保存在现有 `options_json.session` 中，无需更改数据库建表版本；保存、重启和配置导入导出保留这些选项。清空覆盖项会删除旧值，不与旧配置递归合并。

当前没有声称覆盖 Xshell 的全部属性：RLOGIN、GSSAPI、任意键映射、VT 初始化模式、触发器/突出显示规则和 X/Y/ZMODEM 不属于本次已实现设置。RDP、串口和日志/脚本继续通过已有专用入口配置。

## 验证入口

- `npm run check`：类型、语言目录、单元/集成测试和构建。
- `npm run test:xshell-workspace`：临时本机数据、回环 SSH、工具栏显示/拖动/锁定、命令迁移与导入导出、活动终端隔离、属性保存及即时外观、PTY 类型/尺寸、键盘映射、初始目录、真实丢包自动重连和手动停止。
- `npm run test:xshell-workspace:package`：对应安装包验收；已加入各平台发布工作流，等待下一次发布时执行。

测试不连接用户已保存的服务器，不改动实际 Xshell 会话或生产凭据；下载文件重定向到临时测试目录。
