# Hornet Remote Suite 软件详细设计说明书 V1.0
## 第2章 统一工作台 UI 详细设计

修订日期：2026-09-24。目标：一个产品内完成四类套件任务；对象模型见第1章。

## 2.1 主窗口与信息结构

默认1440×900，最小1024×720；支持高 DPI、键盘导航、深色/浅色/高对比主题。颜色不能作为唯一状态提示。

```text
标题栏 / 菜单 / 快速连接 / 命令面板
侧栏：主机、收藏、工作区、隧道、打印、设置
工作区：混合标签组 [终端] [文件] [X11] [RDP/VNC] [编辑器]
底部：任务 / 传输 / 日志 / 可选构建与问题
状态栏：当前主机、协议、连接状态、凭据锁定、后台任务数
```

视图共用 TabManager 与分屏树，不分别建立 TerminalTabs、EditorTabs、DesktopTabs 三套生命周期。协议特有工具栏由视图贡献，关闭操作交由 ViewCoordinator。

## 2.2 新建连接

先选择协议，再显示对应字段。SSH/SFTP 要求主机、端口、用户和认证配置；RDP/VNC 展示桌面参数；串口选择设备/波特率；本地终端选择 shell；X11 选择 SSH 启动配置或 XDMCP；打印在打印中心建队列。

提供“保存”和“保存并连接”，保存配置不能隐式连接。端口为1—65535，主机禁止控制字符；IPv6 地址独立解析。秘密不进入 Zustand、localStorage 或 URL。表单输入秘密时仅短暂驻留内存，提交/关闭即释放引用，不宣称 JavaScript 可以保证物理擦除。

## 2.3 主机树与认证中心

主机树支持文件夹、标签、搜索、收藏、最近连接、批量编辑与导入预览。节点展开显示多个协议配置及运行中的视图。在线状态来自连接事件，不能通过一个 SSH 状态推断整个主机所有协议可用。

认证中心支持密码、加密私钥引用、Agent、交互认证配置，展示引用该凭据的连接列表。修改凭据只影响下一次认证；不自动断开现有任务。无法解锁时允许只保存主机配置。

## 2.4 混合标签与恢复模型

```typescript
type ViewKind = "terminal" | "files" | "x11" | "desktop" | "editor" | "print";
interface ViewDescriptor {
  viewId: string;
  kind: ViewKind;
  profileId?: string;
  title: string;
  dirty: boolean;
  restoreState: Record<string, unknown>;
}
type LayoutNode =
  | { kind: "tabs"; viewIds: string[]; activeViewId?: string }
  | { kind: "split"; direction: "horizontal" | "vertical";
      ratio: number; children: [LayoutNode, LayoutNode] };
```

持久化只保存 profileId、视图参数、布局、路径等非敏感数据，不保存 connectionId、cookie、认证响应或桌面图像。布局恢复先展示“已断开”，仅用户启用自动连接时重新建立会话。编辑器未保存缓冲单独保护，不能被恢复布局覆盖。

## 2.5 跨功能动作

| 起点 | 动作 | 结果 |
|---|---|---|
| 主机/终端 | 打开文件 | 使用同安全上下文连接，文件面板定位已知目录 |
| 文件目录 | 在此打开终端 | 新 shell；目录参数按目标 shell 转义，禁止拼接未转义路径 |
| 文件 | 编辑 | 打开缓存并记录远端版本；保存时检查冲突 |
| 主机 | 启动 X 应用 | 按21章建立图形会话并显示所属窗口 |
| 主机 | 打开远程桌面 | 内嵌桌面视图，清晰显示协议和剪贴板开关 |
| 任务中心 | 定位来源 | 聚焦关联视图；源视图已关闭时展示任务详情 |
| 打印队列 | 作业详情/取消/重打 | 展示接收状态与系统打印状态，重打创建新作业 |

目录联动采用用户动作或明确启用的 shell integration；不从任意终端输出猜测 cwd，不向终端偷偷发送 pwd。

## 2.6 关闭与后台任务

关闭终端只关闭对应 shell；关闭文件标签不取消传输；关闭桌面释放输入焦点、剪贴板与桌面连接租约；关闭 X11 视图前展示受影响的 X 客户端；未保存编辑器须处理保存/丢弃。

关闭主窗口时汇总传输、打印和图形会话。默认退出应用前处理任务；“后台继续”仅在托盘/打印服务实际可用时提供。UI 退出与 Windows 打印服务停止是独立操作。

## 2.7 终端交互

默认 Ctrl+Shift+C/V 复制粘贴，Ctrl+C 保持中断语义；允许按平台映射。多行粘贴先预览，保留 bracketed paste；广播必须显示目标列表与醒目状态，断线后不向新连接补发。快捷命令、脚本、触发器各有管理界面和执行记录。

## 2.8 错误与能力显示

能力状态统一为 available、unavailable、needsSetup、disabledByPolicy，附原因与修复入口。缺少 X Server、RDP 引擎或打印服务时不得显示连接成功。认证取消、网络错误、主机密钥变化、文件冲突使用不同提示；信任决策不能用一闪而过的 Toast。

## 2.9 组件与验收

核心组件：HostExplorer、CredentialCenter、WorkspaceLayout、ViewHost、TaskCenter、TunnelPanel、PrintCenter、CapabilityBanner。UI 仅订阅第4章事件和调用受限 API；运行时服务状态由后台管理。

验收：HRS-UNI 对应 T-UNI-01/02/03；混合标签焦点、200% DPI、键盘可达、断线标识、后台任务不丢失见第12章。

### 当前实现补充：紧凑顶部与可停靠任务中心（2026-09-24）

- 顶部工具栏 30 CSS px、标签栏 29 CSS px、终端操作行 28 CSS px；移除终端重复元数据行，终端搜索按需展开。标签栏右侧按钮折叠顶部与会话工具栏，保留标签切换入口。
- 任务中心是唯一全局面板，通过 Portal 挂载至当前终端左侧文件列表下方。非终端页回退工作区底部；提供左侧、底部、应用内浮动三种布局。所有页面共享同一任务数据源及暂停/恢复/取消操作。
- 标题拖动进入浮动状态；文件栏下半部与工作区底部 70 CSS px 为停靠目标。拖动时显示停靠提示，Esc 或失焦取消。位置选择器提供不依赖拖动的替代操作。
- 停靠面板可调整高度，浮动面板可调整宽高；分隔条支持键盘。尺寸、位置、折叠状态存入本机 localStorage，读取时校验类型并约束至当前窗口可见范围。切换标签和面板布局不重新创建终端或传输任务。
- 本次仅实现任务中心停靠，不代表任意工作区分屏、多窗口拖出或完整布局树已交付。

### 当前实现补充：多级连接分组树（2026-09-24）

连接管理由平铺卡片改为递归分组树。连接沿用 host_profile.group_path，以 `/` 分隔层级；UI 保存时清理各段两端空格和空段，空路径归入默认分组。现有单层分组无需迁移。完整路径仍受 Profile 的 128 字符约束。

提供根分组、子分组创建和组内创建连接；连接编辑表单支持已有路径建议及手动输入多级路径。分组节点可展开/折叠并显示后代连接总数。搜索命中主机或分组时自动展示祖先链；搜索结束恢复之前折叠状态。空分组与折叠偏好存入本机 localStorage；有连接的分组路径仍随连接持久化与导入/导出。空分组元数据尚未纳入导出格式。

分组树交互修正：分组节点及列表空白处增加右键菜单，分组节点菜单仅允许新建子分组和连接；根分组仅通过顶部或空白处创建，组内创建时锁定上级分组。上下文目标由最近的分组节点解析，子分组创建自动带入完整父路径。创建完成后清空搜索、展开祖先并定位新节点，解决折叠分组下新建节点不可见的问题。菜单支持 Shift+F10、方向键和 Esc，点击外部、滚动或窗口失焦时关闭。

分组删除增量：分组右键菜单新增删除，右侧加号仍仅用于创建。删除以当前路径及其后代为范围，确认后一并永久删除其中的连接配置、关联主机和凭据记录。group.remove 携带成员 ID 与 revision 快照，服务先拒绝活动连接或传输，再在事务内核对完整成员集合并统一删除；任何错误回滚整个事务。空分组及祖先保留策略在本机分组目录同步处理。默认分组不可删除。


### 当前实现补充：多语言与配色扩展（2026-10-14）

语言注册表包含 zh-CN、zh-TW、en、ja、ko、de、fr、es，选择器使用各语言自称。zh-CN 使用应用原文，en 为完整英文目录，zh-TW 为完整繁体目录；另外五种语言各包含 267 条常用界面文案。查询顺序为所选语言、英文目录、原文，不把英语回退项标记为已翻译。仅应用文案进入翻译函数；保持原有首尾空白、参数占位符和插值数据，远端提示、用户名、指纹、路径和终端输出不转换。设置页说明详细技术文案的英文回退边界。目录随包离线加载，日期使用所选 locale，document.lang 同步设置。

新增 Solarized 浅色、Dracula、Nord、Gruvbox、One Dark、Rosé Pine 和暖色浅色，连同原有方案共 11 个固定界面主题及系统跟随选项。新增配色覆盖所有既有界面颜色变量，使用共享变量映射及独立调色板，涵盖正文、背景、面板、边框、焦点、按钮及警告状态。经典浅色继续沿用紧凑 Windows 风格规则。终端增加对应方案及高对比度，共 11 个独立终端配色，部分包含 ANSI 16 色；界面主题与终端配色不联动修改。

界面偏好沿用 hornet.appearance.v1，终端偏好沿用 hornet.terminal.preferences.v1。非法或缺失的界面语言/主题分别恢复默认值，避免丢弃另一项有效设置。保存成功才发布状态；存储写入失败时保留原选择。界面切换重渲染标签，不改变终端资源 ID；xterm 通过 options.theme 热更新。繁体/日/韩使用系统字体回退，不下载外部字体。设置对话框适应较长翻译文本及窄窗口。

验收入口：tests/unit/appearance.test.ts、tools/check-locales.mjs、npm run test:appearance。验证主题颜色实际不同、菜单快捷键可达、会话输出保留、主题与语言重启恢复；完整翻译与操作系统诊断本地化仍是后续范围。

### 终端内容右键菜单与异步剪贴板（0.0.3）

终端内容区域与标题菜单分别处理：内容菜单提供复制、粘贴、全选、清屏及搜索，标题菜单继续负责分屏和重命名。右键按下时保存选区快照，菜单选择后操作对应终端并恢复输入焦点；无选区禁止复制，已关闭终端禁止粘贴。Shift+F10 打开内容菜单，方向键选择，Escape 关闭并返回终端。

Electron 剪贴板 readText/writeText 必须 await；主进程只返回可克隆文本或 null，错误通过既有安全响应返回。preload 串行处理剪贴板请求，保证快速复制后粘贴读取已完成的写入；失败不会阻塞后续请求。多行粘贴沿用确认逻辑，异步读取后再次检查会话存活与当前目标。

八种语言提供菜单名称及现有操作翻译。桌面回归使用延迟 Promise 剪贴板替身，验证编辑菜单、鼠标选择、内容右键、分屏目标、快捷键、长度限制、失败恢复及关闭保护；不读取或覆盖真实系统剪贴板。
