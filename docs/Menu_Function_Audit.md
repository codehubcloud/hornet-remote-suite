# 菜单功能检查（0.0.24）

本轮修复可点击但未生效的入口，并补齐常用终端菜单。高级灰色占位项目尚未全部实现，不能将本次发布理解为所有 Xshell 功能均已支持。

| 菜单 | 本次结果 | 验证 |
| --- | --- | --- |
| 查看 → 全屏 | 原生窗口全屏、F11 切换、Esc 退出，勾选状态同步 | 真实 Electron 窗口状态 |
| 查看 → 十六进制查看器 | 只读本地文件，按 4 KiB 分页，显示偏移、十六进制与 ASCII | 二进制文件上传与跨页偏移 |
| 编辑 → 复制为 RTF | 同时写入纯文本与 RTF，保留 Unicode，转义 RTF 控制符 | IPC 与 RTF 格式测试 |
| 编辑 → 粘贴选择内容 | 向当前活动终端粘贴选中文本，多行粘贴须确认 | 双终端选择与实际收包 |
| 编辑 → 选择屏幕 | 仅选中当前可见行；全选仍包含滚屏 | 实际终端选择与复制 |
| 编辑 → 查找上一个/下一个 | 复用当前关键词，支持 Shift+F3/F3；关闭搜索栏后可重新显示 | 实际搜索结果 |
| 文件 → 打印/打印预览/页面设置 | 终端文本预览、A4/Letter、横向排版，调用系统打印对话框 | 拦截打印调用，验证内容、设置与临时窗口清理 |
| 文件 → 粘贴/开始日志状态 | 正在连接或已断开时禁用输入和开始日志 | 连接状态检查与现有断线测试 |
| 窗口 → 全部关闭/除此之外全部关闭 | 可处理只有空白标签的工作区 | 菜单条件检查 |

已有会话管理、工具栏显隐/恢复/排序/锁定、快速命令、文件管理、脚本执行、会话属性、终端重连、终端日志、主题及帮助入口继续由现有测试覆盖。

尚未实现并继续禁用的独立功能包括 ZMODEM、Solaris 快捷键、密钥/身份验证配置管理、按键映射编辑器、突出显示集、触发器、多窗口及层叠；文件工作区仍有独立本地选项卡、视图样式、FTP 命令、传输计划等占位；打印中心及 X11 工作区也保留部分高级占位。这些菜单显示“尚未实现”，与因当前连接状态而暂时不可用的菜单区分。
