# 14.11 崩溃收集设计

本地保存模块、版本、堆栈和脱敏状态；上传默认关闭，用户预览并选择发送。Crash dump可能含秘密和文档内容，不能宣称自动脱敏；收集与上传单独同意。诊断默认不包含终端原文、打印内容、私钥与完整环境变量。

# 14.15 回滚设计

更新前保存程序版本和第11章一致性数据库快照，活动任务未处理完不自动安装。应用更新/原生引擎/数据库schema共同登记版本；失败恢复兼容程序与配套快照。涉及新数据写入时不能简单回退旧db丢掉新增数据，应停止写入进入修复流程。所有回滚包也须验证签名。

# 14.22 统一安装、后台服务与能力探测

一个安装器管理桌面应用与固定版本的X Server、RDP/VNC桥、PrintHelper；按选定组件安装，工作台显示缺失能力。图形组件不从未知可执行路径启动；检测启动能力、端口占用与本地权限。

默认按用户安装核心桌面。LPD服务模式、监听接口及防火墙规则为显式安装选项；只在需要时请求系统权限，不能为了TCP515或打印让整个Electron以管理员长期运行。端口被系统LPD占用时提示迁移/换端口，不自动停止别人的服务。

卸载先停自己安装的服务、清理自己的规则/临时cookie/端口，用户数据与打印暂存是否删除由用户选择；不影响其他X Server或打印服务。核心在无公网、无账号登录环境可用，更新/云服务失联不阻断本地使用。
