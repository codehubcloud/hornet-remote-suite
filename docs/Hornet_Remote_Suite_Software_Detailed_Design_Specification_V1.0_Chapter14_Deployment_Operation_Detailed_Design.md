# Hornet Remote Suite 软件详细说明设计书 V1.0

# 第14章 部署与运维详细设计

------------------------------------------------------------------------

# 14.1 设计目标

部署与运维模块负责保证 Hornet Remote Suite
在个人开发环境、企业环境、私有化环境中的稳定运行。

目标：

-   快速安装
-   自动配置
-   企业批量部署
-   日志采集
-   故障定位
-   自动升级
-   安全回滚

------------------------------------------------------------------------
