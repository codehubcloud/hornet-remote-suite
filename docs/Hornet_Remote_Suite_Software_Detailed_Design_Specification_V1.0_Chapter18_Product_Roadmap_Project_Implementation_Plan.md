# 18.14 风险分析

## 技术风险

风险：

Electron性能。

措施：

-   模块拆分
-   Worker优化
-   Native扩展

------------------------------------------------------------------------

## 竞争风险

竞争：

-   Xshell
-   SecureCRT
-   VSCode Remote

策略：

差异化：

-   AI
-   企业管理
-   SSD/Firmware场景优化

------------------------------------------------------------------------

## 安全风险

风险：

-   插件安全
-   AI误执行

措施：

-   权限模型
-   审计
-   用户确认
