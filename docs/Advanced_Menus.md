# 菜单与高级工作区操作

从 0.0.25 起，原来的高级菜单占位项已接入实际操作。灰色状态表示当前连接类型、选择内容或会话状态不满足条件。

## 窗口与终端

- “查看 → 全屏”使用系统窗口全屏，F11 切换、Esc 退出。
- “窗口 → 新建窗口 / 层叠”管理独立工作窗口，最多 8 个。关闭某个工作窗口只关闭该窗口内的会话，最后一个窗口沿用退出确认。
- 终端标签右键“将标签移动到窗口”移动现有终端，保留画面、历史和连接，不重新登录。正在连接或进行 ZMODEM 传输时不能移动。
- “工具 → 按键对应”可设置按键组合与固定发送文本。`\e`、`\r`、`\n`、`\t`、`\xNN` 分别表示 ESC、回车、换行、制表符和十六进制字节。
- “突出显示集”按固定文字匹配终端输出并标记颜色；“触发器”显示提示或发送固定文字。新规则默认关闭，检查后勾选启用。触发器按行匹配，限制执行频率，只有活动终端会自动发送。
- “Sun (Solaris) 快捷键”向当前连接发送 Sun 终端对应的按键序列。

## 主机密钥与身份验证

“主机密钥管理者”显示已信任指纹，可以删除；删除后，下次连接重新确认。“用户密钥管理者”支持导入私钥、生成 Ed25519 / RSA 3072 / ECDSA P-256、导出公钥与显式导出私钥。保存的私钥由系统安全存储加密；生成时可另设私钥口令。引用中的密钥需先解除配置绑定才能删除。

“身份验证配置文件”保存可复用的用户名、认证方式及可选密码、用户密钥。在新建或编辑 SSH 会话中选择配置，保存连接后生效。查看已保存密码不会替换原密码；勾选清除可删除保存的密码。锁定凭据库后停止自动使用存储的秘密。

## 文件管理

文件工作区的“查看”菜单提供状态栏、传输队列、文件夹树、会话日志和四种显示方式。本地或远端面板获得焦点后，“编辑”的复制、粘贴、全选和查找作用于该面板；本地与远端之间的粘贴提交真实传输。目录传输需要 SFTP，先比较并确认计划；不覆盖已有目标。剪贴板中的来源连接或本地授权关闭后，需要重新选择。

“命令 → 同步浏览”绑定当前本地、远端目录，随后浏览子目录时联动另一侧。另一侧缺少目录时显示错误；离开绑定目录范围或重新选择本地根目录会关闭同步浏览。它只联动浏览，不自动传输文件。

FTP / FTPS 的“传输类型”支持二进制、文本和按扩展名自动选择，影响之后创建的任务。文本使用 FTP `TYPE A`，上传按 CRLF、下载按 LF 转换并验证规范化内容；需要保持原始字节时选择二进制。已有任务恢复沿用原传输类型。

“FTP命令”执行 NOOP、SYST、FEAT、HELP、STAT、PWD、SITE、CWD、CDUP、MKD、RMD、DELE 并显示真实响应；认证、TLS、数据端点和传输状态命令交由专用功能管理。删除命令在服务器直接生效。

## 传输预订

在文件工作区打开“工具 → 传输预订”，选择 SSH / FTP 连接、方向、远端路径、时间，再通过系统对话框选择本地源文件或下载目标。应用运行时到点提交任务，进度在任务中心显示。应用关闭期间错过的计划，在下次启动后等待“立即执行”，不会静默补传。

配置发生修改后旧计划拒绝执行，请重新创建。提交失败不自动重试，先检查错误和任务中心；应用异常退出时未确认的提交结果也需要人工核实。计划不保存密码；到点时仍可能需要身份验证。

## ZMODEM

在 SSH 终端运行远端 `rz` 后，通过“文件 → 传输 → 发送 ZMODEM”选择本地文件；运行远端 `sz 文件名` 后，选择“接收 ZMODEM”及本地接收目录。远端需要安装兼容的 rz / sz 工具。只有用户明确开始后才启用协议检测，传输期间暂停普通终端输入；可在对话框取消，60 秒无数据会超时。

接收拒绝危险文件名和已有同名目标，临时文件完成后才提交。单个接收文件上限 512 MiB，一次最多 100 个文件、合计 1 GiB。这里提供 SSH 终端内的 ZMODEM，不替代 SFTP 的目录同步与断点续传。

## 打印中心与 X11

打印作业可选中后“另存为”原始数据，单独提交或提交全部挂起作业；可设置默认队列、删除作业和查看日志。删除记录及暂存文件不会取消已进入系统打印队列的作业。若批量提交出现不确定结果，会停止后续提交，避免重复打印。

X11 工作区的复制、粘贴作用于当前选中的文字或最近编辑的表单输入框。独立 X Server 应用的剪贴板仍由该显示服务器及远端应用管理。
