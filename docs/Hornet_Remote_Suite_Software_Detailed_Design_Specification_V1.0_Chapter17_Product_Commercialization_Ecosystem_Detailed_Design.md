# Hornet Remote Suite 软件详细说明设计书 V1.0

# 第17章 产品商业化与生态设计

------------------------------------------------------------------------

# 17.1 设计目标

商业化体系用于支撑 Hornet Remote Suite 从开发工具向商业软件产品演进。

目标：

-   建立产品版本体系
-   支持个人开发者和企业客户
-   支持License商业模式
-   建立插件生态
-   建立开发者社区
-   支持云服务运营

------------------------------------------------------------------------

# 17.2 产品定位

统一桌面套件 = SSH/增强终端 + SFTP/FTP + X11图形应用/远程桌面 + LPD打印 + 共享主机、认证、任务与工作台。IDE/AI/企业平台为扩展。

完整功能基线见第1、24章。不能用“Xshell + Xftp + AI”替代Power Suite四类核心用途；所有“支持”宣传须有第12章证据。

# 17.24 商业方案状态与基础能力

Community/Professional/Enterprise/Ultimate及收费、支付平台均为待定商业方案，不是用户已确认的实施需求。技术上保持一个安装器与一致工作台；X11、RDP/VNC和LPD属于套件能力，不依赖AI订阅。

具体版本权益必须在产品决策后填入逐项功能表；任何停用/授权变化不能破坏已完成传输数据、取消正在提交的打印或阻止导出用户配置。遥测默认关闭，启用需明确选择，不采集终端正文、文件内容、凭据或打印文档。
