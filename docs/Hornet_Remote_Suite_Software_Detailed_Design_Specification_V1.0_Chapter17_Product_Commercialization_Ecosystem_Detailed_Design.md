# Hornet Remote Suite 软件详细说明设计书 V1.0

# 第17章 产品商业化与生态设计

------------------------------------------------------------------------

# 17.1 设计目标

商业化体系用于支撑 Hornet Remote Suite 从开发工具向商业软件产品演进。

目标：

-   建立产品版本体系
-   支持个人开发者和企业客户
-   支持License商业模式
-   建立插件生态
-   建立开发者社区
-   支持云服务运营

------------------------------------------------------------------------

# 17.2 产品定位设计

Hornet Remote Suite定位：

    下一代企业级远程开发与运维平台

    =

    Xshell

    +

    Xftp

    +

    VSCode Remote

    +

    AI Agent

    +

    企业DevOps平台

核心能力：

-   SSH远程连接
-   SFTP文件管理
-   Remote IDE
-   AI智能助手
-   Plugin生态
-   企业管理

------------------------------------------------------------------------

# 17.4 Community版本

目标：

个人开发者。

功能：

-   SSH Terminal
-   SFTP
-   基础Session管理
-   基础插件

限制：

-   无企业管理
-   无高级AI
-   无审计

------------------------------------------------------------------------

# 17.5 Professional版本

目标：

专业开发人员。

增加：

-   Remote IDE

-   高级Terminal
-   文件同步
-   高级插件
