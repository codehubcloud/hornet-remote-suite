# Hornet Remote Suite 软件详细设计说明书 V1.0
## 第12章 测试与验收详细设计

修订日期：2026-09-24。以下为计划和门槛，当前仓库尚无实现验收结果。需求映射见第24章；每条测试保存版本、环境、步骤、预期、结果与证据。

## 12.1 测试层次与工具

TypeScript 统一使用 Vitest；Native 使用 GoogleTest；Electron UI 使用 Playwright，原生窗口/打印机补充 Windows 集成测试及人工验收。UT 不访问真实 SSH 或传输1GB文件；协议互通、故障注入和大文件属于 IT/ST/PT。Mock 通过不能替代真实引擎验证。

PR 运行类型检查、lint、UT、基础集成和文档检查；夜间运行真实协议、故障、GUI 与性能测试；发布必须跑安装包级回归、签名校验、离线安装和升级回滚。

## 12.2 测试环境

默认性能基准：Windows 11 x64，8逻辑核、16GiB RAM、SSD；远端 Linux VM 4 vCPU/8GiB、SSD，1Gbps LAN、RTT ≤5ms、无丢包。记录准确 CPU/OS/引擎/驱动/构建版本、加密算法和 GPU，测试时无其他重负载。

协议夹具：固定版本 OpenSSH（密码/密钥/交互认证/跳板）、FTP、X11 应用与 XDMCP 显示管理器、Windows RDP、VNC、lpr 客户端、虚拟打印机及一台真实打印机。凭据为专用测试数据；外网服务不是核心 CI 前置条件。Linux/macOS/ARM64 在对应原生机器另建报告，不复用 Windows 结果。

## 12.4 性能目标（未实测）

| 测试ID | 负载与测量方法 | 候选门槛 |
|---|---|---|
| T-PERF-01 | 空白配置冷启动30次，从进程启动到主工作台可交互；已知主机密钥与本地密钥SSH连接30次 | 启动p95 ≤3s；LAN SSH就绪p95 ≤2s，人工MFA另计 |
| T-PERF-02 | 20终端，其中4路各持续1MiB/s输出10分钟；输入注入到IPC写出计时；另跑100空闲终端8小时 | 输入处理p95 ≤50ms；无>500ms连续UI冻结；终端未消费队列≤1MiB/路 |
| T-PERF-03 | 10GiB单文件与10任务并发；同机同服务器同算法原生sftp作基准，各跑5次 | 单文件吞吐≥基准80%；20次可恢复故障全部哈希正确；错误来源必须拒绝续传 |
| T-PERF-04 | 1920×1080桌面，受控LAN，持续窗口移动/滚动10分钟 | 活跃画面≥25fps，输入到呈现p95 ≤150ms；队列≤2完整帧 |
| T-PERF-05 | 10万目录项、列表虚拟化；测首批200条和滚动，记录服务器扫描时间 | 首批可显示后UI交互p95 ≤100ms；不得等待全部排序后才显示任何状态 |
| T-PERF-06 | 20连接混合负载8小时，关闭视图并完成GC观察；记录全进程私有内存 | 基准套件总私有内存目标≤2GiB；暖机后空闲回落，无连续单调增长 |

所有性能报告保存原始数据与 p50/p95/max。达不到候选门槛时修改实现或公开修订门槛并说明依据，不能用“不卡顿”“稳定”“接近带宽”代替结论。

## 12.5 扩展和高级兼容验收

M3 按第24章每个 C-* 行建立子用例；分别记录 supported/partial/unsupported 与证据。至少覆盖 GSSAPI、PKCS#11、OpenSSH CA、终端仿真、文件 FXP/命令行、X 扩展/字体、多显示器和打印格式。未指定具体引擎的条目必须保留阻塞状态。

M4 IDE 测试远端版本冲突、LSP进程崩溃、URI映射与Agent安装回滚；插件测试授权撤销、越权与沙箱逃逸；AI 测试提示注入、数据外发、审批对象变更和停止。AI 测试验证权限和操作结果，不断言模型必须输出某一条固定shell命令。

## 12.6 发布门槛与报告

M1/M2 对应阶段的所有核心用例100%通过；开放 P0（数据损坏/秘密泄露/系统性崩溃）与 P1（核心流程不可用）均为0。平台未测试不得列为支持；性能超标必须有明确处理结论。覆盖率是辅助指标，不替代端到端验收。

报告字段：需求ID、测试ID、提交哈希、安装包哈希、OS/架构/引擎、夹具版本、复现步骤、预期/实际、日志或录屏、缺陷ID、执行人和日期。每次正式发布附第24章兼容矩阵快照。
