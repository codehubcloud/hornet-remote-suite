# 帮助菜单

帮助菜单提供与终端、文件、图形和打印工作区共用的入口：

| 项目 | 行为 |
| --- | --- |
| 分步使用引导 | 10 步高亮界面导览，支持上一步、下一步、跳过及完成；可随时重新开始 |
| 用户使用指引 | 首次启动自动显示；12 章详细操作步骤，支持目录、搜索、上一章/下一章，以及帮助 PDF；以后可随时从此入口重新打开 |
| Hornet 帮助 / F1 | 应用内离线使用指南，涵盖会话、认证、终端、快速命令、文件、界面、快捷键及支持范围 |
| 打开帮助PDF | 本地生成 A4 PDF，交由系统查看器打开；无需网络；文件位于用户数据目录的 help 子目录 |
| 访问网站 | 打开公开安装包仓库 README |
| 访问技术支持 | 打开公开仓库 Issues |
| 发送反馈意见 | 打开新 Issue 页面，用户自行填写并提交 |
| 检查更新 | 查询公开发布仓库 latest；显示版本比较、发布说明，提供下载页面与失败重试 |
| 关于 Hornet | 显示实际版本、平台、架构、Electron、Chromium、Node.js 版本 |

详细指引正文提供简体中文、繁体中文和英文，其他语言使用英文正文；指引按钮、搜索及菜单跟随八种界面语言，颜色跟随当前主题。帮助 PDF 包含原有简要说明及完整的详细指引。更新检查最长等待 10 秒，不依赖 SSH 后台服务，不下载或安装程序；每次仅由用户点击触发，不上传连接、密码或日志。PDF 生成最多等待 20 秒，系统查看器未配置时可重试。

## 首次启动与日常查看

使用新的应用用户数据目录启动时，先显示用户使用指引；点击“开始使用”、右上角关闭按钮或按 Escape 后，记录本机已查看状态，再按原有偏好显示会话窗口。后续重启不重复弹出指引，也不会改动会话窗口原有的“启动时显示此对话框”选项。首次使用本功能的已有用户同样会看到一次指引。尚未关闭就退出应用时，下次仍会显示。

日常通过“帮助 → 用户使用指引”打开。左侧目录切换章节，顶部搜索会匹配标题和操作步骤；搜索结果为空时可清空关键词重新查看全部章节。正文单独滚动，底部可翻章或打开离线 PDF。关闭指引不会连接服务器或执行示例命令。

十二章内容：首次安装、新建连接及保存用户名/密码、会话与连接状态、终端复制粘贴与查找、标签分屏与属性、上传下载及同步、快速命令及颜色、日志回放与脚本、图形/桌面/转发等工具、语言主题及工具栏、备份升级与支持、故障排查及快捷键。内容包含实际入口、操作步骤和功能的平台范围。

编辑已保存密码的连接时，密码框默认显示圆点。点击眼睛可查看原密码，再次点击隐藏；取消或关闭窗口后再次编辑会恢复隐藏状态。仅查看或修改名称、说明等设置时，保存保留原密码；直接输入可替换密码。修改主机、端口、用户名或认证方式会清除已显示的旧密码，需要重新输入。凭据库锁定或系统加密不可用时提示无法读取，保留原凭据，不显示虚假的明文。

## 分步使用引导

在首次显示的用户使用指引中点击“开始分步引导”，或选择“帮助 → 分步使用引导”。引导按欢迎、新建会话、会话管理、快速连接、终端、任务中心、快速命令、语言主题、帮助、开始使用共 10 步介绍软件。每一步高亮对应的实际区域，并显示说明及当前进度。

点击“下一步”或右方向键继续，点击“上一步”或左方向键返回。可随时点击“跳过引导”或按 Escape 退出；最后一步点击“完成引导”。“用户使用指引”按钮可切换到详细手册。首次从指引启动导览后，完成或跳过才按原有偏好显示会话窗口，后续不会自动重复弹出首次指引；帮助菜单可以重新开始导览。

引导支持八种语言，跟随当前主题及窗口尺寸调整位置。区域被隐藏时使用可见备用入口，或显示提示卡片；不会自动改变工具栏偏好、打开连接配置、连接服务器或执行命令。Tab 和 Shift＋Tab 只在引导按钮内移动。

对外链接固定到公开发布仓库，renderer 不能请求打开任意 URL 或本地路径。反馈不会自动发送。更新结果拒绝草稿、预发布版本及无效版本，限制响应大小；服务器提供的外部链接不作为打开目标。

验证命令：在 src 中运行 npm run check、npm run test:help；实际打包后运行 npm run test:help:package。测试使用独立用户目录，替换浏览器/PDF 查看器打开动作及更新服务器响应；PDF 文件由真实 Chromium 打印引擎生成。五个平台的发布工作流均执行实际包验收。

实现依据：[Electron PDF 文档](https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions)、[Electron shell 文档](https://www.electronjs.org/docs/latest/api/shell)。
