# Hornet Remote Suite 软件详细说明设计书 V1.0

# 第15章 安全详细设计

------------------------------------------------------------------------

# 15.1 设计目标

安全模块用于保证 Hornet Remote Suite
在个人开发、企业研发、私有化部署环境中的安全运行。

目标：

-   身份可信
-   数据安全
-   通信安全
-   权限可控
-   操作可审计
-   插件可信
-   企业合规

------------------------------------------------------------------------

# 15.4 Token设计

采用：

JWT。

结构：

``` json
{
"sub":"user001",
"role":"developer",
"expire":123456789
}
```

包含：

-   用户ID
-   角色
-   有效期
