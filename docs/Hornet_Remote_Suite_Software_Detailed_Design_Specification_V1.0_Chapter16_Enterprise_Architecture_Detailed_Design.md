# 16.23 企业控制面边界与租户隔离

本章属M4，企业平台不在核心协议数据通路：客户端直接连接目标服务器，企业服务负责配置、策略和审计。集中强制命令限制需服务器/堡垒机配合，不能仅靠客户端UI防止本机管理员绕过。

所有企业业务表、外键、查询、缓存key和对象存储key携带tenant_id；请求租户来自已验证身份与成员关系，不信任客户端传参。使用RLS或等效服务端强约束，测试跨租户ID猜测、导出、异步任务和WebSocket订阅。第11章原简化表不作为完整企业schema。

策略含版本、签名、有效期与离线行为；过期/撤销的敏感操作按企业配置拒绝，新旧配置冲突返回revision冲突。同步仅传非敏感配置，凭据默认本地绑定，不能同步本机secret_ref。审计有容量和保留限制，发送失败可重试去重，但不得自动上传终端/打印正文。

容灾目标需在服务SLA中量化RPO/RTO并演练；当前不声称高可用已实现。
