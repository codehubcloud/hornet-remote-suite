Hornet Remote Suite 0.0.25

- 修复原生全屏，支持 F11 切换、Esc 退出和窗口状态同步。
- 完成原灰色高级菜单：多窗口、层叠、保留连接与画面的终端标签移动。
- 增加主机指纹管理、用户密钥生成与导入导出、加密身份验证配置复用。
- 增加终端按键对应、文字突出显示、限流触发器和 Sun Solaris 快捷键。
- 增加 SSH 终端 ZMODEM 文件收发，必须手动开始并选择本地文件或目录。
- 补齐本地文件选项卡、复制粘贴、目录树、日志、显示方式和同步浏览。
- 增加 FTP 二进制 / 文本 / 自动传输类型和 FTP 命令窗口。
- 增加持久化传输预订；关闭期间错过的计划在启动后等待手动执行。
- 完成打印作业原始数据导出、批量提交与删除、默认队列和操作日志。
- 修复小窗口下文件列表被表头挤压的问题，新增实际菜单操作回归。
