Hornet Remote Suite 0.0.14：首次使用指引、分步引导与连接状态改进。

- 首次启动显示十二章离线用户使用指引，支持目录、搜索、翻章和导出帮助 PDF；以后可从帮助菜单重新打开。
- 增加十步界面高亮引导，支持上一步、下一步、跳过和完成，可从帮助菜单重新开始。引导跟随主题和窗口大小，文案覆盖八种界面语言。
- 服务器无法访问时尽快在终端显示目标、失败原因及重试入口；无响应的连接尝试设有超时，认证输入保留正常交互时间。
- 底部会话属性准确区分正在连接、连接失败、已连接和已断开；连接中不会提前显示已连接。
- 本地与自动构建显式准备 Electron 运行时，完善依赖恢复和独立打包目录的使用文档。

- 远程连接断开时，在终端正文中追加断开原因、实际错误信息、会话名称和断开时间，标签同步显示“已断开”。区分主动断开、远端关闭、终端会话退出和网络异常。
- 后台标签页和同一 SSH 连接下的多个终端分别保留断开记录；重复关闭事件不会重复追加提示。重新连接仍需经过正常认证，不重发历史命令。
- 断开后保留终端历史输出，禁止继续向已关闭会话输入、粘贴或发送脚本；保留复制、搜索和重新连接入口。
- 处理全屏程序与终端显示模式，断开提示追加到原有输出之后，避免光标回退覆盖历史。断开提示覆盖全部八种界面语言。
- 继续包含 0.0.12 的快速命令配色、会话属性、工具栏恢复、完整帮助菜单、加密保存密码、分屏标签及 Ctrl＋滚轮缩放等功能。覆盖安装保留连接、分组和配置。

源码保留在私有仓库，公开仓库仅提供安装包、校验文件及说明。Windows x64、macOS Intel/ARM64、Linux x64/ARM64 安装包分别在对应系统构建并验证。

本地 PowerShell/CMD、串口、原生 RDP、VcXsrv 管理和系统打印提交目前使用 Windows 适配器；VcXsrv 需另行安装。尚未配置商业代码签名或 Apple 公证。不宣称完整覆盖 Xshell。
