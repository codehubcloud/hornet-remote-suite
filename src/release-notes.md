Hornet Remote Suite 0.0.8：终端标签随窗格分屏。

- 水平/垂直分割现在同时排列现有终端标签与终端内容，各标签直接位于对应窗格顶部，移除下方重复标题；不创建新终端或 SSH 连接。
- 各窗格标签继续支持右键分割、取消分屏、重命名与关闭；分隔条支持拖动和方向键。关闭到一个窗格后恢复普通标签栏。
- 公共工作台和工具入口位于文件栏上方，隐藏文件栏时移入首个窗格；工作台往返保留分屏。文件列表继续跟随当前选中的终端目录。
- 保留现有终端实例、输出内容及连接，搜索、日志和文件按钮作用于对应窗格；新增各平台实际打包程序的分屏标签及会话连续性验收。
- 终端正常退出或关闭时丢弃尚未完成的终端输入回调，避免已结束的会话留下 `SCRIPT_CLOSED` 全局错误；活动会话的输入失败仍正常提示。
- 覆盖安装保留连接、分组与配置。

继续包含 0.0.7 的透明 Logo 与合并式标题菜单栏：

- 使用用户提供的透明 PNG，保留透明通道与完整图形，更新各平台应用、安装/卸载程序、快捷方式、任务栏、原生 RDP、关于窗口与 favicon 的图标。
- 去掉独立白色标题栏和标题文字，菜单与窗口按钮合并为顶部一行，左侧显示透明 Logo，空白处可拖动窗口。
- 保留系统原生最小化、最大化/还原、关闭按钮；按钮配色跟随界面主题，macOS 为左侧系统按钮预留空间。
- 工具栏折叠时保留顶端菜单与窗口操作，继续支持菜单鼠标操作和 Alt 快捷键。
- 各平台新增实际打包程序的标题栏、透明图标和窗口布局验收。覆盖安装保留连接、分组与配置。

继续包含以下 0.0.5 与 0.0.4 修复：

- 点击关闭立即显示确认框，使用已收到的任务状态，不再先等待可能超时的后台查询。
- 选择退出后同时尝试关闭后台和终端日志，清理最多等待 5 秒；超时后结束后台和应用，不再无限等待。取消退出会保留当前程序和会话，重复点击关闭不叠加确认框。
- 增加真实打包程序的故障验收：阻断后台请求和 shutdown 回应，并故意卡住隔离测试窗口的 renderer，确认仍能退出且后台进程已结束。测试不操作用户真实主机、数据或安装目录。

继续包含以下 0.0.4 修复：

- 休眠、唤醒和主进程长时间调度停顿不再直接触发后台强制结束或消耗请求超时；缺少心跳时先探测，再判断后台是否失去响应。
- SFTP 子系统错误会使对应文件通道失效并允许重新建立，避免未处理的错误事件结束整个后台。后台确已退出时，新请求立即返回错误，不再等待两分钟。
- SFTP 优先在远端通过 `sha256sum` 计算完整 SHA-256：支持时上传后不再把临时文件完整下载回来校验，下载前后校验也在远端计算。不支持命令或仅允许 SFTP 的服务器自动回退到原有流式完整校验。
- 校验期间显示已处理字节数，并区分远端校验。FTP/FTPS 继续使用流式校验，也显示字节进度。源文件复核、续传前缀校验、覆盖冲突保护和原子提交继续保留。
- 增加校验数据流停滞超时，保留暂停、取消和失败后恢复；远端校验取消只关闭对应命令通道。
- 继续包含 0.0.3 的终端复制/粘贴和右键菜单修复。
- 继续兼容旧版 LF/CRLF 数据库，覆盖升级保留连接、分组和配置。

发布流程使用实际打包程序和独立临时数据验证历史数据库升级、剪贴板与右键菜单、远端 SHA-256、上传零回读、单次下载及校验期间普通请求的响应。网络或服务器断开仍可能结束对应连接；本次不承诺自动恢复已断开的终端。

统一会话管理、SSH/SFTP、FTP/FTPS、Telnet、终端分屏、文件传输、多语言和主题。
