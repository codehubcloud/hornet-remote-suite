Hornet Remote Suite 0.0.12：快速命令配色、会话属性、工具栏与完整帮助入口。

- 新增 Xshell 风格快速命令栏、窗格和管理器：命令集管理、排序、导入导出、是否回车、Ctrl＋F1–F12，仅发送到当前终端。右键命令按钮可编辑纯色、线性/径向渐变、角度与文字颜色；支持预设、预览和恢复主题默认，重启及导入导出保留外观。
- 会话属性改为分类设置：连接、身份验证、SSH 跳板、保活、重连、终端、键盘、外观、文件目录和快速命令；用户名与密码相邻，密码支持小眼睛查看。说明可在新建/编辑连接时填写，并与名称、主机、用户名、协议、端口等一起显示在窗口底部。
- 每会话可设置终端类型、初始行列、退格/回车、字体配色、保活和初始远端目录；可选择启用 SSH 异常断线自动重连、间隔及时间上限，不自动重发历史命令。手动断开会暂停自动重连。
- 顶部右键支持菜单栏、标准按钮、地址栏、链接栏和锁定工具栏。取消锁定后可拖动排序，链接栏可保存当前会话。修复取消菜单栏勾选后无法通过顶部右键重新勾选的问题；左上角菜单按钮也可恢复。
- 补齐“帮助”菜单：Hornet 帮助（F1）、打开帮助 PDF、访问网站、技术支持、发送反馈意见、检查更新和关于。帮助正文及生成的 PDF 可离线使用，正文提供中文/英文；其他界面语言显示英文正文。网站、支持和反馈打开公开下载仓库及 Issues 页面，由用户自行提交。
- 更新查询从公开发布仓库读取最新稳定版本，支持新版/已是最新版、网络失败和重试；版本按数字比较，不提示降级。打开发布页面后选择安装包，不自动下载或安装。关于窗口显示实际应用版本、系统架构和运行时版本。
- Windows 原生 RDP 能力探测允许最多 30 秒冷启动，响应等待输出流排空后解析；超时仍有界退出并提供原因。
- 继续包含加密保存密码、终端断线状态、标题右键操作、分屏标签、Ctrl＋滚轮缩放、透明图标、大文件 SHA-256 优化和后台无响应退出保障。覆盖安装保留连接、分组和配置。

Windows x64、macOS Intel/ARM64、Linux x64/ARM64，共七个安装包与 SHA256SUMS。源码仍保留在私有仓库，公开仓库仅提供安装包、校验文件及说明。

本地 PowerShell/CMD、串口、原生 RDP、VcXsrv 管理和系统打印提交目前使用 Windows 适配器；VcXsrv 需另行安装。尚未配置商业代码签名或 Apple 公证。标签移动到独立窗口、RLOGIN、GSSAPI、X/Y/ZMODEM 等未实现功能仍保留为不可用，不宣称完整覆盖 Xshell。
