Hornet Remote Suite 0.0.26

- 更新下载的进度、按钮和提示统一跟随软件语言，补齐八种界面语言的更新文案。
- 加宽检查更新窗口，下载量、实时网速及剩余时间可在桌面窗口内一行显示。
- 本版本起，软件内下载并校验的更新会保留安装记录；暂缓安装后，下次启动软件或再次检查更新可直接点击安装，无需重新下载，断网时也可使用有效缓存。
- Windows 安装器的“不关闭应用程序”改为保留安装包、稍后安装，不再登记系统登录任务或要求重启电脑；确认自动关闭后安装并重开应用的流程保持有效。
- 恢复与安装前检查版本、平台、文件大小和 SHA-256，拒绝损坏、缺失、未完成及旧版本安装包。
- 修复 Windows“查看 → 全屏”勾选与实际窗口状态相反的问题；F11 切换、Esc 退出和菜单状态同步正常。
