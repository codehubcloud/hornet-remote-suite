Hornet Remote Suite 0.0.3：修复终端复制/粘贴，并增加终端内容右键菜单。

- 修复“编辑 → 复制/粘贴”出现 `An object could not be cloned`：正确等待 Electron 异步剪贴板接口，并按顺序处理连续复制/粘贴。
- 终端文字区域右键提供复制、粘贴、全选、清屏和搜索；保留选中文本，分屏时操作右键所在的终端。
- 支持 `Shift+F10` 打开菜单、方向键选择、`Escape` 返回终端；多行粘贴仍需确认，已关闭终端禁止粘贴。
- 继续兼容旧版 LF/CRLF 数据库，覆盖升级保留连接、分组和配置。

各平台安装包均验证异步剪贴板、真实鼠标选择、编辑菜单和终端右键菜单，测试使用独立剪贴板替身。

统一会话管理、SSH/SFTP、FTP/FTPS、Telnet、终端分屏、文件传输、多语言和主题。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `.exe`，支持选择安装目录 |
