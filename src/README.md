# Hornet Remote Suite — 桌面源码

当前版本为 **0.1.0 核心实现**，按设计文档 M1 路线建设。整个工程位于 `src`，其内部目录遵循设计第20章。没有把尚未实现的原生能力用外部启动器或模拟成功代替。

## 启动

当前工作区已准备项目内 Node.js 工具链，直接双击项目根目录的 `start.cmd` 即可构建并启动应用。启动失败时窗口会保留错误信息。

不要双击 `run.ps1`：Windows 可能弹出“选择一个应用以打开此 .ps1 文件”。`start.cmd` 会显式调用 PowerShell，不依赖文件关联，也不会修改系统执行策略。

也可以在项目根目录的 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\run.ps1
```

新机器安装 Node.js 24 LTS 后：

```powershell
cd src
npm ci
node node_modules/electron/install.js
npm run dev
```

Electron 运行时下载故障时，Windows x64 可运行 `node tools/install-runtime.mjs`，它从官方 GitHub Release 下载，并对照 Electron npm 包提供的 SHA-256 校验。下载需要网络；安装后核心功能离线可运行，不需要云账号。

`npm start` 使用已有构建产物；`npm run dev` 先构建再启动。启动脚本会移除开发环境可能继承的 `ELECTRON_RUN_AS_NODE`，避免 Electron 被当作 Node 运行。不会修改系统 PATH。

Windows 启动回归：构建后运行 `npm run test:startup`，检查实际启动入口能显示窗口，以及再次启动能恢复已最小化的窗口。该测试会短暂显示测试窗口，使用独立临时数据目录。

## 启动会话窗口

启动时默认显示“会话”窗口，布局参考 Xshell 的会话选择器：工具栏、分组位置栏、详细列表和底部启动选项。可搜索名称、主机、用户名、说明和分组；点击列标题排序，单击选择，双击或 Enter 连接。支持新建连接、属性编辑、复制、删除，以及创建分组/子分组。选中父分组时包含其子分组连接；“上级”返回父级。

取消“启动时显示此对话框”后，下次启动直接进入工作台。始终可通过“文件 → 打开…”、Alt+O 或工具栏“打开会话”再次打开。关闭窗口不会自动连接。新建/编辑保存后返回列表；复制只复制配置，不复制凭据。说明和修改时间来自本机数据库，旧配置无需迁移；修改时间由后端生成。

“查看 → 主题 → 经典浅色”使用浅灰菜单/工具栏、蓝色标签与选择框，启动窗口使用浅蓝标题和白色列表；其他界面主题和终端独立配色继续保留。“工具 → 更改语言…”可选择简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español。参考程序的未实现命令仍置灰，菜单外观相近不代表全部功能等价。

新增界面回归：`npm run test:sessions-ui`（仅使用独立临时数据和本机 SSH 夹具）。

## 已实现的操作

- React 工作台、主机搜索/分组、混合终端/文件/编辑标签、任务中心、错误反馈。
- SQLite 主机配置、乐观版本检查、配置导入/导出、最近工作区恢复提示。
- 真实 SSH：密码、私钥文件、系统 Agent 接口、交互认证、首次主机指纹核验、变更拒绝。
- SSH 本地/远程 TCP 端口转发：独立租约、自动分配端口、连接数/双向字节统计、停止监听和断线清理。
- 内嵌 VNC 桌面：noVNC 画面与键鼠输入、缩放、Ctrl+Alt+Del，使用独立 SSH 租约及一次性鉴权桥。
- X11 图形应用：VcXsrv 自动管理、每会话独立显示/进程/cookie、认证就绪检查、退出回收；也支持手动选择外部 Xauthority。新增局域网 XDMCP 查询与独立桌面窗口。
- RDP 实验入口：Windows 系统控件的受管理独立窗口，密码经私有 stdin 传递，强制身份验证及 NLA。
- LPD 多队列：来源白名单、持久暂存、手动提交 Windows RAW/UTF-8 文本打印及不确定状态恢复。
- 独立协议服务进程；同一配置的并发连接共用握手，视图和任务分别持有租约。
- xterm.js 远程终端、窗口尺寸同步、多编码收发（内部统一 UTF-8）、有界输出队列与逐块确认、多行粘贴提示。
- SFTP 浏览、新建目录、重命名、文件/空目录删除、上传、下载。
- 后台队列（全局4、每主机2）、幂等创建、暂停/取消/恢复、临时文件、SHA-256 校验。
- 恢复前校验源文件与目标前缀；源变化拒绝续传。普通传输仍拒绝覆盖；同步预览可明确选择覆盖策略并绑定内容快照。
- 不超过128KiB的UTF-8文本编辑；内容冲突检查、支持OpenSSH原子重命名时提交。
- 系统安全存储保护的密码保险库、凭据锁定；系统后端不可用时不降级明文。
- 受限 Preload API、来源/frame验证、Zod运行时参数校验、本地文件选择授权。

## 操作说明

1. 新建 SSH 配置，保存名称、主机、端口和用户名。
2. 打开终端或文件，输入认证资料；首次连接核对远端主机指纹。
3. 同一主机再打开另一个视图会复用 SSH。关闭终端不结束文件视图或正在运行的传输。
4. 文件标签中先选择左侧本地目录，再勾选文件批量上传或下载；终端侧栏仍可通过系统对话框选择单个文件。目标必须使用尚不存在的名称。
5. 暂停任务后可恢复。重启后的未结束传输先显示暂停，不自动重新写入。
6. 凭据锁定阻止后续读取保存的密码，不会主动断开已有连接；重新显式输入并选择保存后解锁保险库。
7. 工作台下方“SSH 端口转发”选择主机与转发类型，填写目标地址/端口后创建。监听端口填 `0` 自动分配，实际端口显示在列表中；可以在没有终端标签时独立创建隧道。动态 SOCKS5 不需要固定目标，改为填写允许的目标地址/端口列表，逗号分隔，留空允许全部。
8. 本地转发从本机回环端口连接 SSH 服务器可访问的目标；远程转发从服务器回环端口连接本机可访问的目标。支持 `127.0.0.1` / `::1`，尚不开放通配监听。SSH 协议只返回远程端口，无法证明服务器实际绑定接口；使用远程转发前须核对服务端 `GatewayPorts` 策略。
9. “停止隧道”会关闭该隧道的监听与活动流，不断开其他终端/文件租约。退出应用会关闭全部隧道；当前隧道规则与统计仅保存在内存，不会在重启后自动监听。
10. 动态代理创建后，在支持 SOCKS5 的客户端配置显示的回环地址及端口，并启用代理端 DNS（例如 `curl --socks5-hostname 127.0.0.1:实际端口 https://example.com`）。代理只支持无认证 TCP CONNECT，不支持 UDP/BIND/用户名密码；本机其他进程也可使用该监听。地址白名单按请求中的域名/IP精确匹配，不按DNS解析结果限制IP网段，不支持通配子域名；`*` 或空列表允许全部地址。

## 图形与打印的使用条件

- **VNC**：工作台“图形桌面与打印”选择SSH主机，填写该服务器可访问的VNC地址和端口（通常5900），点击“打开 VNC 桌面”。随后在标签页输入VNC密码（如服务器要求）。目前只支持SSH传输路径，不自动同步本机剪贴板，不恢复断开的桌面。
- **X11**：选择已安装的 `vcxsrv.exe`，明确启用网络监听，选择 SSH 主机与窗口模式，然后执行远端图形命令（如 `xclock`）。程序自动分配 :10–:99 显示号、独立随机 cookie 与独立 SSH 连接，最多 8 个显示。需要远端 sshd 允许 X11 转发并安装 xauth。引擎启动必须通过正确 cookie 接受、错误 cookie 拒绝检查；剪贴板关闭。VcXsrv TCP 监听本机 IPv4 接口，不能仅绑定回环；程序不修改防火墙，需要使用系统规则限制来源。外部 X Server 模式仍需手动启动和选择 Xauthority，仅允许一个外部显示转发会话。
- **XDMCP**：选择明确的私网/VPN IPv4 服务器和本机接口，可先查询 UDP 177（可自定义）。确认未加密直连后打开独立桌面窗口；服务器需允许 XDMCP，并能回连 `6000+显示号`。显示管理器负责登录认证，界面的“请在独立窗口登录”只表示引擎已启动，不表示远端已登录。支持定向查询，不做自动子网扫描、广播发现或 SecureXDMCP；选择的接口用于 XDMCP 出站地址，不能限制 VcXsrv TCP 的监听接口。停止按钮和应用退出均回收受管理引擎。
- **RDP**：点击“检测 RDP 引擎”，成功后填主机、用户、域和密码，打开独立原生窗口。证书须通过系统身份验证；没有忽略证书错误选项。窗口由Hornet管理，但它不是内嵌工作台桌面，也未完成真实RDP互通验收。
- **LPD**：读取系统打印机，选择队列名与格式，配置监听地址/端口和精确来源IP白名单后启动。默认回环监听，可选择本机LAN地址；程序不会修改防火墙。标准端口515，其他端口必须由lpr客户端显式指定。LPD不验证提交用户名，不能把白名单当强认证。任务收到后为 `held`，需要手动“提交打印”；`submitted`仅表示交给系统，`unknown`须到Windows打印队列核实，不能自动重打。
- LPD只接受单个 `f`/`l` 数据文件引用；UTF-8文本使用固定字体与边距，RAW须由打印机支持对应语言，不能把任意PDF当通用RAW。默认单任务10MiB、总暂存100MiB、4个接收连接。监听配置不随重启恢复；作业保存在用户数据目录的 `print-spool`，当前无自动保留清理、重打、已提交任务取消或后台服务安装。退出应用停止接收；已提交给系统的打印可能继续。

第三方实现来源：VNC使用 [noVNC 1.7.0](https://github.com/novnc/noVNC)（MPL-2.0，完整许可材料位于依赖包docs目录）及ws；RDP使用系统自带ActiveX控件；LPD依据 [RFC 1179](https://www.rfc-editor.org/rfc/rfc1179)。项目没有打包或分发X Server/FreeRDP二进制。

## 当前边界

- 当前不是24章全部功能的完成版。内嵌RDP、FTP、上游代理、IDE/LSP、插件、AI及企业服务尚未交付。VNC/X11/LPD和RDP PoC的范围及差异见上述说明和设计21.8/22.8/23.8。
- VNC尚无后台强制只读、帧尺寸限制、自动重连、分辨率调整和性能验收；X11 已验证 VcXsrv 21.1.16.1 与真实 xclock、独立显示及 cookie 隔离，实际 Linux/OpenSSH 和 Linux 显示管理器登录仍需目标环境验收，字体/GLX/IME/性能矩阵未完成；RDP只完成控件初始化，尚无服务器登录验证；Windows打印适配尚未向实体或虚拟打印机提交测试文档。
- 静态与动态转发合计最多32个活动隧道，每隧道最多64个同时连接；仅请求回环监听。监听状态不代表目的服务可达；单条目标连接失败显示错误，监听继续运行。SOCKS握手及建连有15秒总时限、64KiB初始报文上限，统计不包含SOCKS握手字节。尚未执行真实 OpenSSH 服务端、IPv6目标连接、GatewayPorts 配置矩阵及长时吞吐测试。
- 私钥、Agent和MFA接口已编码，但需要目标环境互通验证；现有自动化协议夹具主要覆盖密码认证。
- 不自动重连或重放远程命令。关闭/重启后打开新的shell，不能恢复原shell进程；tmux尚未接入。
- 工作区仅恢复最近主机提示；跨标签任意布局和完整快捷键系统尚待实现。
- 文件标签支持本地/远端双面板；选择本地根目录后可浏览子目录、创建目录并批量传输普通文件。本地最多显示5000项，远端最多10000项；已提供递归传输、缺失项补齐、双向合并同步和同名文件策略；删除传播、自动调度和大目录虚拟化尚待实现。
- 文本编辑提供版本冲突检查，不能保证与外部写入者之间的原子比较交换。终端输出、文件内容不会自动写入日志。
- 传输执行全文件/前缀校验，可靠性优先，尚未达到第12章吞吐门槛。取消/冲突留下的 `.hornet-<taskId>.part` 暂存文件保留供诊断，可在确认任务结束后手动清理。
- 普通下载使用同卷硬链接实现不覆盖提交；同步中明确选择的覆盖使用同目录临时文件校验后重命名替换。服务端覆盖需要 OpenSSH posix-rename 扩展，缺失时拒绝覆盖。
- 单机单用户、单主窗口。安全存储保护依赖操作系统账户，不抵御同账户恶意进程。未实现应用内容锁屏。
- 还没有签名安装包、自动更新和跨平台认证，不能作为生产环境完整替代品发布。

### 终端文件侧栏

打开 SSH 终端默认显示左侧 SFTP 文件栏，自动收起主机列表；顶部“主机列表”可再次展开。拖动分隔条或聚焦后按左右方向键调整宽度，宽度保存在本机；隐藏文件栏不会断开连接。文件列表复用 SSH 认证，独立于 Shell 生命周期。路径可手动输入，也可启用下述 Linux 终端目录跟随。

侧栏支持目录导航、当前目录名称筛选、上传、下载、新建目录、重命名、删除、UTF-8 小文件编辑和三位八进制权限修改。权限修改使用 SFTP chmod，拒绝符号链接和特殊文件；设置 000–777 会清除特殊权限位，远端路径并发变化仍存在竞争。终端搜索可用 Ctrl+Shift+F 聚焦，Enter/Shift+Enter 查找下一个/上一个，Esc 返回终端；搜索仅覆盖当前终端保留的滚屏内容。

### 紧凑工具栏与任务中心布局

顶部使用紧凑工具栏与标签栏。点击标签栏右侧箭头折叠/展开顶部工具栏和会话操作行；折叠状态保存在本机。终端搜索默认隐藏，通过“搜索终端”或 Ctrl+Shift+F 打开，Esc 或 × 关闭。

任务中心默认停靠在当前终端的文件列表下方；非终端页面显示在工作区底部。按住任务中心标题拖动可切换为应用内浮动面板；拖到文件栏下半部或工作区底部松开即可停靠。也可使用标题栏中的“左侧 / 底部 / 浮动”选择框切换。停靠面板顶部边缘可调高度，浮动面板右下角可调尺寸；分隔条支持方向键。− / ＋ 折叠与展开，Esc 取消正在进行的拖动。位置、尺寸与折叠状态自动保存；窗口尺寸变化时浮动面板保持在可见区域。左侧停靠的任务中心随文件栏一起隐藏，恢复文件栏即可重新显示。布局操作不会重建 SSH Shell 或停止传输。

### 多级连接分组

连接管理现在按分组树显示。点击分组名前的箭头展开/折叠，数字表示该分组及全部子分组的连接数量。顶部 ⊞ 新建根分组；分组行的 ⊞ 新建子分组，＋ 弹出菜单，选择在该分组新建子分组或连接。编辑连接时可从“分组”输入框选择已有路径，也可以输入 `生产环境/北京/数据库` 创建多级路径或移动连接。

搜索名称、主机或分组时自动展示命中路径；清空搜索恢复原折叠状态。连接的分组路径沿用 SQLite 的 group_path，随连接导入/导出；空分组目录和折叠状态保存在当前应用的本地偏好中，不随连接配置导出。原有单层分组自动兼容，空分组名显示为“默认分组”。

分组右键操作：在分组上右键，提供“新建子分组”、“新建连接”和“删除分组”，子分组的上级固定为当前分组；在列表空白处右键，可新建根分组或默认组连接。分组按钮聚焦后也支持 Shift+F10，菜单内用上下键选择、Enter 执行、Esc 关闭。新建分组后自动展开其祖先并滚动至新节点。

### 删除分组

右键分组或子分组，选择“删除分组”。确认后移除该分组及全部子分组，并永久删除其中的连接配置。分组中有正在使用的连接或传输时会阻止整个删除操作。默认分组作为系统分组不可删除，其子分组仍可删除。右侧 ＋ 菜单继续只显示两项新建操作。

删除前核对分组内连接的版本和成员集合，连接发生并发变化时中止并刷新。连接配置及关联主机、凭据记录的删除在同一个 SQLite 事务内完成；空分组目录同步从本机偏好移除。删除最后一个子分组时保留其父分组。

### 终端分屏与目录跟随

打开两个及以上终端后，右键任一终端标签或分屏标题，选择“水平分割”（上下排列）或“垂直分割”（左右排列）。操作排列所有已打开的终端，不新建 Shell；可拖动分隔条调整比例。“取消分屏”恢复单终端显示，其余终端仍保持连接。标题右键“重命名终端”仅修改本次会话标题，不修改连接配置。关闭标签或分屏标题 × 仅关闭对应终端；布局与临时标题不跨重启恢复。

左侧文件栏“跟随终端”按钮默认关闭。开启后约每 800ms 获取当前选中 Shell 的真实工作目录，目录变化时刷新文件列表；关闭后保留当前浏览位置。搜索针对当前选中分屏，切换分屏也会切换目录跟随目标。

跟随当前支持可通过 SFTP 或独立 SSH exec 查询 `/proc` 的 Linux 主机。会话创建时先探测 `/proc/self`（单次查询最多 8 秒，包含 SFTP 初始化；SFTP 失败后回退 SSH exec），再以带 PTY 的 SSH exec 启动短小的 `sh` 包装命令，记录 PID 后 exec 登录 Shell；不修改服务器启动文件，也不把查询命令写入正在运行的终端。优先通过 SFTP readlink 读取 `/proc/<PID>/cwd`；失败后使用独立 SSH 通道执行固定 readlink 查询，并在后续轮询中沿用此通道类型，处理相对路径、带空格路径和失败的 cd；读取到的是物理目录路径。机制依据 [Linux /proc 文档](https://docs.kernel.org/filesystems/proc.html)。

不支持的主机或拒绝 SSH exec 的服务器回退普通 Shell，跟随区域显示原因。该跟踪针对最初的登录 Shell，不跟随其内部的二次 ssh、容器、tmux 或子 Shell；远端 SFTP chroot/权限限制也可能使目标目录不可浏览。目录不可用时保留原列表并显示错误。升级后需重新打开终端使用目录跟随。

### 统一菜单与快速连接

顶部菜单集中提供会话新建/导入/导出、主机列表、当前标签关闭、终端搜索和重命名、标签切换、分屏以及现有工具入口。快速连接栏支持完整会话名称直接连接，也支持 host、user@host:port、ssh://user@host:port 和方括号 IPv6；新地址先补充连接配置，然后“保存并连接”。不接受地址内嵌密码。Alt+D 聚焦快速连接；折叠顶部时菜单和地址栏一起隐藏。

本机套件参考及功能差距见 [参考记录](../docs/Xmanager_Power_Suite_8_Local_Reference.md)。菜单按当前工作区组织，可用项接入真实操作，尚未实现的命令置灰，不表示整个 Xmanager 套件已完成等价实现。专用桌面验证：在 src 目录执行 npm run test:appearance。

### X11 会话状态与停止

X11 会话列表显示主机、启动命令、准备/连接/启动/运行状态、活动转发通道数，以及命令退出码或信号。启动过程中也可以点击“停止 X11 会话”；停止只释放该会话的 SSH 租约，不关闭其他终端或文件视图使用的共享连接。若 SSH 认证仍在进行，迟到的连接结果会释放本会话租约，不再执行启动命令；共享认证本身仍由认证对话框管理。

启动命令正常退出或命令通道关闭后，已有图形通道继续保留，直到用户停止会话。是否还能创建新的 X11 通道取决于 SSH 会话和服务器；当前 ssh2 在启动命令通道关闭后不再接受该会话的新 X11 通道。命令非零退出、被信号终止或 SSH 断线会回收转发，并保留失败原因。本次运行最多保留 20 条会话记录（含活动会话），超限时淘汰最早的失败记录，也可手动移除；命令输出不写入日志，不自动重跑命令。

选择无效 Xauthority 时保留上一次有效配置。握手 cookie、协议格式、超时和本地 X Server 连接错误会显示在所属会话中；单个转发通道失败不会断开其他通道。会话活动期间禁止替换认证配置。受管理模式使用专用 SSH 连接，每个会话独立认证和转发；外部模式复用原有 SSH 租约。

### 文件双面板、打印队列和 X11 启动预设（2026-10-10）

文件标签左侧为本地工作目录，右侧为远端 SFTP。支持子目录导航、名称筛选、新建本地目录、普通文件多选上传/下载；成功后自动刷新，传输由原任务中心管理。下载到左侧当前目录，不覆盖同名文件。目录联接和符号链接显示但不能进入或传输，切换目录授权和关闭视图会释放浏览授权，已提交任务继续执行。每个批次遇到错误停止后续提交，已创建任务在任务中心保留。

打印中心最多保存32个队列，分别映射系统打印机和 RAW/UTF-8 格式；共用监听接口、端口及来源白名单。队列支持暂停接收、恢复、修改和删除，作业支持按队列/状态/文件/主机/用户过滤。删除有接收中或待提交作业的队列会被拒绝。历史作业保留原打印机映射，不因修改队列而改变；重启恢复队列配置但不自动监听。暂停接收不取消现有任务；启动监听会启用选定的启动队列。

X11 启动预设保存名称、SSH 配置引用、启动命令、显示管理方式、窗口模式、DPI 和外部显示号，可修改、另存、删除和跨启动恢复。不会保存密码、Xauthority 内容或网络监听许可；选择预设后需重新勾选网络监听许可，执行仍由用户触发。

验证入口：npm run test:suite-ui（本地回环 SSH/SFTP、临时目录、LPD 测试作业与预设恢复，不提交真实打印）。

### 递归目录传输与补齐同步

在文件双面板中勾选文件夹后上传，或使用右侧“下载目录”，先显示完整预览，再创建目录并把普通文件加入任务中心；保留空目录。顶部“比较并补齐远端/本地”比较当前两侧目录的条目，补齐目标缺失项，不覆盖、不删除目标内容。默认已有文件列为冲突；可在预览中改用较新优先、本地/远端优先或保留双方副本。双向同步及其边界见下文。

每侧扫描上限 5000 个条目、32 层、90 秒；预览有效期10分钟。符号链接、特殊文件、Windows 保留名称及大小写碰撞不会传输。执行前重新扫描，文件进入队列后还会核对源大小与修改时间，传输继续使用内容哈希校验。遇错停止追加任务，已提交任务及已建目录保留，界面显示实际提交数量。远端并发修改路径仍有 SFTP 检查/使用竞态，不提供跨文件原子事务。单文件任务可以暂停/恢复/取消，目录批次暂不提供整体撤销。

### 终端设置、快速命令与文本导出

“工具 → 选项…”（或工具栏 Aa）调整字体、字号、三种配色、光标和滚屏容量，本机保存，直接应用于现有终端；不重启 Shell。降低容量会丢弃超出的滚屏历史。

“工具 → 快速命令”打开可关闭的底部面板，保存/载入/删除常用命令（最多100项，每项8192字符），明确显示当前接收终端。选择命令不会执行；“发送并执行”仅向该终端发送全部行并回车，不广播。命令以本机明文偏好保存，不应保存密码。

“编辑”提供全选、清除滚屏和“导出终端文本”。导出经过终端渲染后的当前缓冲文本至系统选择的位置，最大8MiB UTF-8；不包括已丢弃滚屏，也不是持续日志或录制回放。专用验证：npm run test:terminal-ui。

### Telnet 终端与持续日志

新建连接时选择 Telnet，或在快速连接栏输入 `telnet://host:23`（支持方括号 IPv6）。连接后在终端内手动登录；用户名仅为备注，不使用 SSH 凭据。Telnet 是明文连接。会话支持搜索、现有终端分屏、重命名、显示设置和快速命令；不提供 SFTP 文件栏、目录跟随或 SSH 隧道。

Telnet 已实现流式 IAC、回显/二进制/SGA 协商、XTERM-256COLOR 终端类型和窗口尺寸上报。默认 UTF-8，可在会话属性或工具菜单选择编码；尚未覆盖 LINEMODE 完整行编辑、TLS 和真实设备互通矩阵。

SSH 或 Telnet 终端激活后，在“编辑”菜单选择“开始持续文本日志”或“开始原始终端日志”，通过系统对话框选择新文件名。文本日志去除显示控制序列，原始日志保留终端输出字节（不含网络协议协商）。从启动记录时开始，切换标签、分屏或清除滚屏不影响记录；“停止当前日志”或终端工具栏“● 日志”结束记录，终端继续交互。关闭终端会自动结束日志；“终端日志管理”显示路径、状态和已接收字节数，并可停止其他终端的日志。

文件不会覆盖已有内容；每个终端同时一份日志，最多32份活动日志，单文件100MiB，磁盘积压上限1MiB。达到上限或写入失败会停止日志并显示原因，不中断终端。正常退出会等待关闭，异常进程终止可能丢失缓冲尾部。日志可能包含终端回显的敏感内容；不另行采集按键。文本/原始日志没有时间轴；带时间的 .hrec 录制及回放见下文。当前没有自动轮转或跨启动日志索引，重启不会自动记录。

验证入口：`npm run test:telnet-logs`；使用回环测试服务和临时日志文件。

### 本地 PowerShell / CMD 与串口终端

“文件 → 本地终端”选择 Windows PowerShell 或命令提示符 CMD，可填写存在的绝对起始目录，留空使用当前用户目录。通过 node-pty 1.1.0 的 ConPTY 引擎提供真正的交互终端，支持尺寸调整和 Ctrl+C；使用当前 Windows 账户权限。PowerShell 不加载用户 Profile，CMD 不运行 AutoRun。当前支持 Windows 10 1903 及更新版本，不提供自定义可执行文件、WSL 或其他平台 Shell。

“文件 → 串口终端”枚举 COM 设备，也可手动输入端口号。设置波特率、数据位、停止位、校验位、无/RTS-CTS/XON-XOFF 流控、CR/LF/CRLF 换行及本地回显后打开。使用 serialport 13.0.0；端口在本应用内独占，打开失败或拔出会显示错误。支持选择字符编码；真实设备的波特率、流控和接线兼容性仍需实机验证，尚无 Hex 发送、BREAK/DTR/RTS 手动操作和 X/Y/ZMODEM。

两类终端复用标签、标题重命名、已有终端分屏、搜索、显示设置、快速命令和持续日志；不显示远程 SFTP 文件栏。关闭一个终端只结束该本地会话/释放串口，其他终端继续运行。正常退出应用会回收会话；后台服务异常退出时仍需检查正在运行的本地程序状态。最近一次成功打开的参数保存在本机界面偏好，不加入 SSH 主机分组或远程配置导出，也不在重启时自动打开设备。

本地与串口终端合计最多16个。每终端未确认输出达到512KiB时暂停读取，累计缓冲硬上限1MiB；每秒接受最多64KiB输入，串口待发送缓冲最多64KiB。串口软件暂停读取不保证物理线路无损，持续大流量须使用设备支持的流控。关闭标签不保证设备已消费所有排队发送字节。

验证：`npm run test:device-terminals`。本地终端使用真实 PowerShell/CMD；串口收发使用 SerialPortMock 独立夹具，桌面只枚举端口，不向物理设备发送数据。原生依赖和 ConPTY 运行文件需要随 node_modules 保持完整；不应只复制 dist 目录。第三方依据与许可证见 [node-pty 官方仓库](https://github.com/microsoft/node-pty)、[SerialPort 官方接口](https://serialport.io/docs/api-serialport/) 及安装包内 LICENSE。

菜单支持分隔线、子菜单、勾选状态、快捷键提示、Alt 访问键、上下左右键及 Escape。折叠工具栏后使用 Alt+F 等访问键可重新展开菜单。Alt+D 聚焦连接地址，Alt+N 新建连接，Alt+O 显示主机列表；Ctrl+Shift+F 搜索当前终端，Ctrl+Shift+C/V 复制/粘贴，Ctrl+Shift+L 清除终端缓冲显示，Ctrl+Shift+F4 关闭当前标签。多行粘贴保留确认。文件工作区额外支持 Ctrl+N/O、Ctrl+A（远端文件选择）、Ctrl+F（远端目录筛选）和 F5；输入框内保留原有 Ctrl+A 行为。

文件“命令”菜单的向右传输作用于左侧勾选项，向左传输作用于右侧勾选项；重命名/删除/权限作用于单个远端选中项。打印“文件”菜单创建或删除当前队列，“队列”菜单编辑属性、启用/暂停当前队列。没有对应选择时禁用相关命令；尚未实现的命令有独立提示。当前仍未实现参考软件全部菜单操作，具体包括 RTF/ZMODEM、专有脚本 API / 密钥管理界面、独立会话窗口及部分高级打印/显示选项。

验证：`npm run test:locales` 检查应用文字及菜单标签的英文覆盖；`npm run test:appearance` 验证菜单键盘操作、主题/系统跟随、语言持久化及运行中终端不重建；`npm run test:suite-ui` 验证文件和打印菜单的实际操作。新增语言需扩展 appearance.ts 的语言列表及 i18n.ts 的词典选择，翻译资源位于 renderer/locales。


### 会话重连、批量关闭与键盘广播（2026-10-11）

“文件 → 重新连接”与工具栏重连按钮为当前 SSH/Telnet 标签建立新 Shell，保留标签标识、标题、位置和分屏；SSH 传输连接仍有效时复用它，不中断其他终端或 SFTP/传输租约。底层连接断开后重新建立和认证。失败保留原标签；认证期间关闭标签，迟到的新会话被释放。“重新连接所有”依次处理现有远程终端，失败停止后续重连，不处理本地/串口。

“窗口 → 全部关闭 / 除此之外全部关闭”处理当前视图和工具标签；编辑器沿用未保存提示，取消后停止后续关闭。关闭管理标签不停止其后台打印/图形服务。

“工具 → 发送键输入到”明确勾选 2–16 个现有终端后，来自任一勾选终端的键盘输入和粘贴发送到全部勾选终端。顶部显示目标和“停止广播”；未勾选终端输入仍仅发送自身。快捷命令保持单终端发送。关闭或重连自动移除旧 terminalId，少于两个目标时关闭广播；不持久化，也不将新会话自动加入。广播是分别发送，不提供跨主机原子执行保证。

### 带时间的会话录制与离线回放

“编辑 → 开始会话录制”或“文件 → 日志”选择新 .hrec 文件，记录从此刻起转为 UTF-8 后的终端输出字节、单调时钟时间和窗口尺寸变化；不记录开始前的滚屏，也不另行记录按键。每终端仍最多一份活动日志。录制最多 16 MiB、10 万事件、7 天，磁盘积压达到上限时停止录制，不停止终端。

“回放录制文件…”或日志管理中的“回放”打开已停止的录制，支持播放/暂停、0.25–8 倍速、拖动时间轴、回到开头。回放在只读终端中处理输出，不创建连接、不注册输入/剪贴板/链接打开回调。文件由系统选择器授权或来自本次运行的日志记录；校验格式版本、时间顺序、事件类型、尺寸及文件上限。旧文本/原始日志没有时间轴，不能冒充有时间的录制。尚不兼容其他产品录制文件，也没有自动轮转或跨启动索引。

### SSH 跳板链

先保存各跳板的直连 SSH 配置，在目标连接属性“SSH 跳板链（按顺序）”中添加最多四跳并调整顺序。下一跳主机名交给上一跳服务器连接；每一跳分别使用自己的认证方式和 host:port 指纹记录，不跳过目标主机验证。终端、SFTP、隧道等复用目标 SSH 连接，因此均可使用该路由。跳板连接单独持有上游租约；目标关闭或连接失败逐级回收，不结束其他独立 SSH 会话。整个连接/认证操作最多 110 秒，超时取消所属认证窗口与通道。

禁止重复/自身引用、Telnet 跳板、嵌套隐式路由和缺失引用；完整链必须按顺序显式列出。仍被引用的跳板不能删除、改成 Telnet 或另设跳板链；分组删除同样检查外部引用。配置导出保留链关系，导入必须同时包含被引用跳板，所有 ID 和引用一并重建，缺失引用整批回滚。未增加 HTTP/SOCKS 上游代理或高级 SSH 认证。

验证：npm run test:session-advanced、tests/integration/jump-chain.test.ts、tests/unit/recordings.test.ts、tests/unit/session-lifecycle.test.ts。以上使用回环夹具和临时目录，不访问真实远端主机。


### 终端编码与脚本自动化（2026-10-11）

SSH/Telnet 会话属性可保存字符编码，导入导出保留；串口对话框同样支持选择。提供 UTF-8（默认）、GB18030、GBK、Big5、Shift JIS、EUC-KR、Windows-1251、Windows-1252、ISO-8859-1。菜单“工具 → 终端编码”仅切换当前终端后续收发，不重新解释历史屏幕；重连使用保存的会话编码。本地 ConPTY 使用 Unicode，不进行额外传输转码。编码需手动与服务端匹配；无法表示的输入由编码器替换为问号，未提供自动检测。接收端保持跨包解码状态，输入端按目标编码发送；Telnet 在编码后转义 IAC。所有文本/原始日志和 .hrec 记录统一 UTF-8；原始日志保留 VT 控制序列，但不是网络字节抓包。

“工具 → 脚本”或“查看 → 脚本管理器”提供发送文本（可追加回车）、等待输出、延时步骤，可新增/删除/上移并保存本机脚本。等待使用区分大小写的纯文本，剥离 ANSI 控制序列，按顺序消费匹配前的输出；从运行开始收集，不读取旧滚屏，不重建光标移动后的屏幕。发送操作等待后端接收确认，不表示远端命令已成功结束，需通过后续等待步骤判断结果。每脚本最多 200 步，每步最多 5 分钟，总时限 30 分钟，未消费输出最多 128 KiB；库最多 30 个脚本、1 MiB。

脚本固定绑定原 terminalId，执行时暂停该终端键盘/快捷命令并退出广播；关闭、重连、关闭脚本窗口、手动停止或超时后，不继续后续步骤。已发送命令不会回滚，若要终止远端进程需另行操作终端。命令明文保存在 localStorage，不宜放置口令。当前不运行任意 JavaScript/Python/VBScript，也不兼容 Xshell 专有脚本 API；无自动登录脚本、正则触发器、条件分支/循环或跨会话脚本。

验证入口：npm run test:terminal-automation；单元/集成覆盖 SSH/Telnet/串口编解码、分片 GB18030、录制 UTF-8、所有权、编码隔离、等待消费、超时、取消和总时限。


### 双向同步与同名文件策略（2026-10-11）

文件双面板选择本地目录后，顶部“双向同步…”或“工具 → 同步文件夹… → 双向同步…”比较当前两侧目录。预览逐项显示方向、复制/覆盖/创建目录/跳过及原因；切换策略会重新扫描和比较，不会立即写文件。只有点击“执行同步”才将文件加入原任务中心，进度、暂停、取消、恢复沿用任务操作。关闭未执行预览不会修改文件；执行中出现错误停止后续加入，已创建目录/已提交任务不回滚。单向“比较并补齐远端/本地”仍默认跳过已有文件。

提供五种同名策略：跳过、较新优先、本地优先、远端优先、保留双方副本。非跳过策略及双向预览对同名普通文件计算 SHA-256；相同内容跳过，不以大小或日期相等冒充相同内容。较新优先仅在两侧时间差大于 2 秒时选择较新侧，否则留为冲突；双机时钟偏差会影响选择，请查看预览。保留双方副本生成带 (local)/(remote) 的新名字，冲突时递增编号；不覆盖原件，对仍冲突的原名再次执行会再建编号副本。单向模式不因另一侧优先而反向写入。

预览在主进程持有不可由界面改写的计划，10 分钟过期；执行前重新扫描元数据。覆盖任务绑定预览时源/目标的大小、修改时间和哈希，在开始及提交前复核目标内容，源及临时文件也校验；变化时拒绝覆盖。上传采用 OpenSSH 原子替换，下载采用同目录 rename；绝不先删除原件再拷贝。不支持原子上传覆盖的服务端会报告失败并保留原件。保留源文件修改时间及已有目标的基本权限；不复制 ACL、所有者或扩展属性。取消提交前任务不会覆盖原件，临时 .part 可能保留用于人工检查，预览不会传输此类文件。提交开始后不能取消，异常提交结果标为冲突供核对，不自动重试。

边界：这是按当前内容/时间决策的双向合并，不保存上次同步基线，也不传播删除；无法区分两侧同时编辑的历史。链接、特殊文件、类型冲突、Windows 名称冲突保留为冲突。每侧最多 5000 条目、32 层，单文件比较 30 秒、内容比较阶段约 75 秒预算（已启动的一对比较会收尾），超时需缩小范围。文件系统和 SFTP 没有条件式 rename；最后一次检查与提交之间仍有外部修改竞态，不能宣称跨机器事务/文件锁保证。

验证：npm run test:file-sync、tests/unit/sync-plan.test.ts、tests/integration/sync-transfers.test.ts；原目录递归/套件桌面回归保持兼容。

### 0.0.2 启动兼容性修复

修复 Windows 安装版读取已有 LF 数据库时误判版本不兼容的问题。结构文件统一 LF，兼容历史 CRLF 校验值，原有连接和配置保留。启动错误通过后台消息显示具体原因。

### 0.0.3 终端复制/粘贴与右键菜单

正确等待异步剪贴板接口，并按顺序执行连续复制/粘贴。终端文字区域右键提供复制、粘贴、全选、清屏和搜索；支持 Shift+F10、方向键及 Escape，多语言与主题一致。多行粘贴仍需确认，已关闭终端禁止粘贴。验收：`npm run test:clipboard` / `npm run test:clipboard:package`。

### 0.0.4 后台存活与大文件校验

后台存活检测和请求超时使用排除休眠及主进程长调度停顿的活动时间；30 秒缺少后台消息时先探测，继续无响应 15 秒才结束后台。SFTP 错误使对应文件通道失效并允许重建，不再作为未处理事件结束后台；后台确已退出时，新请求立即失败。

SFTP 优先通过已认证 SSH 连接在远端运行 `sha256sum`，采用严格路径引用、输出格式校验、超时和取消。成功时上传校验不回下载临时文件，下载源前后复核不重复传回源内容；服务器不支持该命令或禁止 exec 时自动回退完整流式 SHA-256。不会降低源/目标哈希、续传前缀、覆盖冲突和原子提交保护。任务中心显示校验字节数及远端方式；FTP/FTPS 继续使用流式校验，也显示字节进度。远端命令只在完成时返回摘要，中间字节数不代表实时磁盘进度；最终校验仍受服务器磁盘性能影响。

验收：`npm run test:transfer-reliability` / `npm run test:transfer-reliability:package`，使用隔离数据和本机 SSH 夹具，检查上传零回读、单次下载、校验进度、同时查询 X11 状态和电源事件处理。休眠、心跳失联、超时、远端哈希回退及 SFTP 错误另有单元/集成回归；真实网络断开不会自动恢复已有终端。

### 0.0.5 后台无响应时仍可退出

窗口关闭确认使用已经接收的任务状态，不依赖后台 `task.list` 请求；重复关闭只保留一个确认流程，取消后继续运行。确认退出后并行尝试后台 shutdown 和日志关闭，最多等待 5 秒，随后强制结束剩余后台、原生 RDP 辅助进程和应用窗口；不等待 renderer 的 beforeunload。异常退出后的传输沿用历史任务恢复和未知提交冲突规则，需要人工核对目标文件。

`npm run test:shutdown` / `npm run test:shutdown:package` 在独立临时应用中截断后台请求，验证立即确认、取消保留，再故意卡住 renderer，验证接受退出后在限定时间内结束主程序及协议后台。故障注入只由测试驱动在临时进程内完成，应用没有新增故障开关。
